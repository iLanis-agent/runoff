Runoff

"I don't care, you pick" is how group dinners die. Everyone ranks the options once on one phone; instant-runoff math finds the pick the group can actually live with.

Settle a vote

Add the options, pass the phone - each person taps their ranking - then run the runoff. Watch each elimination round: last place drops out, those votes move to the next pick on each ballot, until one option holds a majority. No app installs for the group, no accounts, no 40-message thread.
